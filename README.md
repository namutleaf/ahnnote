# AHNNOTE
내가 쓸 메모 앱 (윈도우 11 특화, 원노트 스타일)

## 만드는 법 (설치 프로그램 필요 없음)
1. 폴더 하나 만들기 (예: `C:\AHNNOTE`) — `Program Files` 아래는 피하세요.
2. 메모장에 `AhnNote.cs` 내용 붙여넣기 → **UTF-8** 로 저장 (파일 이름 `AhnNote.cs`)
3. 메모장에 `BUILD.BAT` 내용 붙여넣기 → 저장 (파일 이름 `BUILD.BAT`)
4. `BUILD.BAT` 더블클릭 → `AHNNOTE.exe` 생성 (아이콘은 exe 안에 들어가고, 만들 때 쓴 임시 아이콘 파일은 지워짐)

빌드할 때 AHNNOTE 가 실행 중이면 먼저 닫으세요.

윈도우 11 기본 내장 .NET Framework 4.x 의 `csc.exe` 로 빌드합니다. (C# 5 문법)

## 상용구 (자주 쓰는 문구)
- 블록을 잡고 우클릭 → `선택한 글을 상용구로 저장` (서식 그대로 저장, 비어 있는 Alt+번호 자동 배정)
- 넣기: **Alt+1 ~ Alt+9**, 또는 도구 모음 `상용구 ▾` / 우클릭 `상용구 넣기 ▸` 에서 클릭
- `상용구 관리...` 에서 이름·단축키·내용 고치기, 순서 바꾸기, 삭제. 저장: `AhnNoteData\_snippets.txt`
- 메인 창과 포스트잇 모두 사용 가능

## 글자색 / 형광펜
- 블록을 잡고 우클릭 → `글자색 ▸`, `형광펜 ▸` (메인 창과 포스트잇 모두)
- 도구 모음이나 우클릭에서 마지막으로 고른 색이 단축키 색이 되고, 다시 실행해도 기억함

## 즐겨찾기
- 페이지에서 Ctrl+D 또는 우클릭 → `즐겨찾기 추가`. 노트북 목록 위 `즐겨찾기` 칸에 모이고, 누르면 그 페이지로 이동
- 페이지 목록에 ★ 표시. 이름 바꾸기·이동·삭제하면 즐겨찾기도 같이 바뀜

## 포스트잇
- 페이지 우클릭 → `포스트잇으로 띄우기`, 또는 페이지를 메인 창 밖으로 끌어다 놓기
- 포스트잇에서 편집 (서식·자동 변환·체크박스 모두 같음). 그동안 메인 창의 그 페이지는 읽기 전용
- 윈도우 제목 표시줄 없이 얇은 위쪽 줄만 표시. 위쪽 줄을 끌어서 옮기고, 테두리를 끌어서 크기 조절
- 위쪽 줄 버튼: `색` 포스트잇 배경색 (포스트잇에만 적용) / `핀` 항상 위에 고정 / `↩` 메인 창으로 돌려보내기 / `×` 닫기
- 다시 실행하면 열려 있던 포스트잇이 같은 자리에 다시 뜸. 저장: `AhnNoteData\_stickies.txt`

## QR로 보기 (스마트폰으로 옮기기)
- 페이지 우클릭 → `QR로 보기` 또는 Ctrl+Shift+Q
- 현재 페이지 글자(서식 제외)를 QR로 표시. 길면 여러 장으로 나눠 `(1/5)` 처럼 번호를 붙임. ← → 키로 넘기기
- `한 장에`: 적게(약 150자, 잘 찍힘) / 보통(약 330자) / 많이(약 650자, 촘촘함)
- 마지막으로 고른 `한 장에` 설정을 기억함
- 회사 보안 규정상 내부망 자료 반출이 허용되는지 먼저 확인하세요

### 아이폰 사용자
1. QR 창에서 `아이폰 단축어 설치` → 아이폰 카메라로 찍고 `단축어 추가` (폰 인터넷 필요, 처음 한 번만)
2. 다음부터는 추가한 단축어 실행 → 본문 QR을 1장부터 차례로 찍기 → 다 찍으면 `취소`. 새 메모에 저장됨
- 단축어 링크는 `단축어 링크 바꾸기...` 에서 바꿀 수 있음 (기본: https://www.icloud.com/shortcuts/5e838a57c9b245b5bdba42f4e72d77f5)

### 단축어 직접 만들기 (단축어 앱)
1. `+` → 이름 `AHNNOTE 받기`
2. 동작: `QR 또는 바코드 스캔` → `메모 생성` (본문: 스캔 결과)
3. 여러 장 이어받기: `반복` (20회) 안에 `QR 또는 바코드 스캔` → `메모에 추가` (메모: 위에서 만든 메모, 내용: 스캔 결과)
4. 다 찍으면 스캔 화면에서 취소. 홈 화면에 추가하거나 설정 → 손쉬운 사용 → 터치 → 뒷면 탭에 연결하면 편함
(iOS 버전에 따라 동작 이름이 조금 다를 수 있음)

## 캘린더 / 알림
- 노트북 목록 맨 위 `▦ 캘린더` 버튼 (오늘 일정 수도 표시)
- 날짜 더블클릭 또는 `+ 일정` → 제목, 라벨 색, 날짜, 시간(없으면 종일), 내용, 알림 최대 5개
- 알림: 30분 전 / 1시간 전 / 1일 전 / 2일 전 / 7일 전 / 직접 설정. 종일 일정은 그날 오전 9시 기준
- AHNNOTE 실행 중에 화면 오른쪽 아래 작은 팝업으로 알림. 꺼져 있는 동안 지난 알림(7일 이내)은 다음 실행 때 모아서 표시
- 검색: 제목·내용. Ctrl+F 검색, Ctrl+N 새 일정, PageUp/PageDown 달 이동, Esc 닫기
- 공휴일: 양력 공휴일 + 설날·추석·부처님오신날(2050년까지 자동 계산) + 대체공휴일(현재 규정) + 2026 지방선거, 2028 총선
- `공휴일 관리`에서 임시공휴일 추가, 바뀐 날 삭제, 해마다 기본값 복원
- 저장: `AhnNoteData\_calendar.txt`, `AhnNoteData\_holidays.txt`

## 노트북 색
노트북 목록에서 오른쪽 클릭 → `색 바꾸기`. `자동 색` 을 고르면 원래대로 돌아갑니다.

## 다크 모드
- 도구 모음 오른쪽 `◐ 다크 모드` 버튼 또는 Ctrl+Shift+D
- 글자색·형광펜·배경색은 다크 모드에서 밝기만 뒤집어 보여주고, 파일에는 원래(라이트) 색으로 저장합니다.
- 설정은 `AhnNoteData\_settings.txt` 에 저장되어 다음 실행에도 유지됩니다.

## 자동 저장
- 입력을 멈추고 약 0.6초 뒤에 자동 저장 (메인 창·포스트잇 공통). 3초마다 한 번 더 확인하고, 창을 닫거나 다른 창으로 옮길 때도 저장
- 강제 종료나 전원 차단 때도 마지막 0.6초 입력만 잃을 수 있음

## 저장 위치
`AHNNOTE.exe` 옆 `AhnNoteData` 폴더
- 노트북 = 폴더, 페이지 = `.rtf` 파일 (워드패드로도 열림)
- 삭제하면 `AhnNoteData\_휴지통` 으로 이동

## 단축키
| 키 | 기능 |
|---|---|
| Ctrl+B / I / U / - | 굵게 / 기울임 / 밑줄 / 취소선 |
| Ctrl+Alt+1~3, Ctrl+Alt+0 | 제목 1~3, 본문 |
| Ctrl+Shift+> / < | 글자 크게 / 작게 |
| Alt+1 ~ Alt+9 | 상용구 넣기 |
| Ctrl+Shift+C / Ctrl+Shift+H | 최근 글자색 / 최근 형광펜 (한 번 더 누르면 원래대로). 처음엔 빨강 / 노랑 |
| Ctrl+1 | 할 일 체크박스 |
| Ctrl+. | 글머리 목록 |
| Ctrl+F / Ctrl+H / F3 | 찾기 / 바꾸기 / 다음 찾기 |
| Ctrl+A C X V Z Y | 모두 선택, 복사, 잘라내기, 붙여넣기, 실행 취소, 다시 실행 |
| Ctrl+Shift+V | 텍스트만 붙여넣기 |
| Ctrl+S | 저장 (자동 저장도 됨) |
| Ctrl+N / Ctrl+Shift+N | 새 페이지 / 새 노트북 |
| F2 / 더블클릭 / Del / Alt+↑↓ | 이름 바꾸기 / 이름 바꾸기 / 삭제 / 순서 바꾸기 (목록에서) |
| Ctrl+휠, Ctrl+0 | 확대·축소, 원래 크기 |
| Ctrl+Shift+D | 다크 모드 켜기/끄기 (도구 모음 오른쪽 버튼도 있음) |
| Ctrl+Shift+T | 항상 위에 표시 켜기/끄기 (도구 모음 오른쪽 버튼도 있음) |

## 자동 변환 (노션 스타일)
| 입력 | 결과 |
|---|---|
| `[]` | ☐ (클릭하면 ☑) |
| `[x]` | ☑ |
| `()` | ○ |
| `->`  `<-`  `<->` | →  ←  ↔ |
| `=>`  `<=>` | ⇒  ⇔ |
| 줄 처음 `# ` `## ` `### ` | 제목 1, 2, 3 |
| 줄 처음 `- ` | • 글머리 목록 (엔터로 이어짐, 빈 줄에서 엔터면 끝) |
| `---` + 엔터 | 구분선 |
